
# Local Food Wastage Management System

## Project Overview

The Local Food Wastage Management System is a Streamlit and MySQL based application that helps reduce food waste by connecting food providers such as restaurants, supermarkets, and grocery stores with NGOs and individuals in need.

## Technologies Used

* Python
* MySQL
* Streamlit
* Pandas
* Plotly

## Features

* Food Listings Management
* Provider and Receiver Information
* Claims Management
* SQL Query Analysis
* Interactive Dashboard
* Data Visualization Charts
* CRUD Operations

## Dataset

* Providers Data
* Receivers Data
* Food Listings Data
* Claims Data

## Dashboard Modules

* Dashboard
* Food Listings
* Providers
* Receivers
* Claims
* SQL Queries
* CRUD Operations

## Outcome

This system helps reduce food wastage and improves food redistribution through data analysis and interactive visualizations.
